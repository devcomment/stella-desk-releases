# Stella Desk

토키노 메리와 하나요 히요리의 방송·채팅·소식을 모아 보는 Windows 비공식 뷰어입니다. 네이버·치지직·스텔라이브의 공식 앱은 아닙니다.

## 설치

[최신 버전 다운로드](https://github.com/devcomment/stella-desk-releases/releases/latest)에서 `StellaDesk-버전-setup.exe`를 받아 실행하세요. Windows 10/11 x64를 지원하며 바탕화면·시작 메뉴에 Stella Desk 바로가기를 만듭니다.

## 업데이트

앱의 **설정 → 앱 업데이트 → 업데이트 확인 → 다운로드 → 재시작하여 업데이트**로 적용합니다. 설정·보관함·시청 기록·로그인 유지용 데이터는 유지됩니다.

0.11.3부터 차등 다운로드를 시도합니다. 설치 파일 캐시가 없거나 차등 다운로드에 실패하면 전체 파일을 받습니다. 완성된 설치 파일은 배포 서명 정보의 크기·해시와 대조하고 설치 직전에 다시 확인합니다.

Windows 게시자 인증서는 아직 없습니다. 앱 내 업데이트 서명과 Windows 게시자 서명은 별개입니다.
